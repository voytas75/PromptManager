## Confirmed baseline and corrected contract

- GUI Notes owns independent `PromptNote` records in the existing SQLite `prompt_notes` table (`id`, `note`, `created_at`, `last_modified`); no prompt relationship, title, or soft-delete. Reuse the table/model; do not create `notes` or change schema, GUI, prompts, Chroma, or SSOT.
- Public family: `prompt-manager note [--limit 20] [--json]`, `note add`, `note show <uuid>`, `note find <literal> [--limit 20]`, `note edit <uuid>`, `note delete <uuid> [--yes]`. Root, family, and leaf help must work through both supported entrypoints.
- `show/edit/delete` use full canonical UUIDs (no prefix lookup). List and find are newest first (`last_modified DESC`, ID tie-break), bounded to 1–100 entries. Literal `find` escapes SQL LIKE wildcard characters; SQLite's default case-insensitivity is ASCII-only; do not claim Unicode casefolding.
- Add and edit accept exactly one of positional text, `--body`, UTF-8 `--file`, `--from-stdin`. Whitespace-only input fails before mutation, matching GUI validation. Text is stripped like GUI. Unreadable/non-UTF-8/oversized files fail cleanly. `--json` is an output selector, not an input source.
- Text output is default. JSON results have one document on stdout and no stderr on success; errors return nonzero and one bounded JSON error on stderr in JSON mode. List/find expose compact previews and IDs; show exposes full text and timestamps. Add/edit return ID and timestamps; delete returns ID. No content in error diagnostics.
- Delete is hard delete via the existing table, matching GUI; require explicit `--yes` for non-interactive execution and for JSON mode, otherwise ask on TTY with a default-No answer. Cancellation must leave record intact.
- The `note` family must dispatch before the full manager/factory imports in both `python -m main` and installed `prompt-manager`. Reads must not initialize Chroma/provider services, schema, or a missing SQLite database. Writes require an existing selected SQLite database with `prompt_notes`; no implicit new catalog creation. Smoke only against disposable isolated data.
